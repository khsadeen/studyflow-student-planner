# 📚 StudyFlow - Student Planner

StudyFlow is a Python desktop application designed to help students organize their academic tasks, deadlines, priorities, and progress through a simple and intuitive graphical user interface.

## ✨ Features

- ➕ Add academic tasks
- 📚 Assign tasks to different subjects
- 🚦 Set task priorities
- 📅 Set due dates
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🔎 Search tasks
- 📊 Track total, pending, completed, and overdue tasks
- 💾 Automatically save task data locally
- 🖥️ User-friendly desktop GUI

## 🛠️ Technologies

- Python 3
- Tkinter
- JSON
- Git
- GitHub

## 🖥️ Application

StudyFlow provides a simple dashboard where students can manage their academic tasks and monitor their progress.

The application currently includes:

- Total Tasks counter
- Pending Tasks counter
- Completed Tasks counter
- Overdue Tasks counter
- Task management table
- Search functionality
- Task priority management
- Due date tracking
